# Búsqueda de negocio propio, escalable

Proyecto para investigar ideas de negocio **nuevas** (que no repitan nada de lo ya visto) y
quedarse con la mejor para ganarse la vida. Las reglas y el estado están en `CLAUDE.md`.

- `investigaciones/`: las investigaciones nuevas y sus Excel.
- `ideas-anteriores/IDEAS-PRUEBA/`: todo lo investigado antes (lista de lo que no se repite).
- `backup-juguetes-madera/`: el proyecto de juguetes de madera, guardado como respaldo.

Para seguir: abrir esta carpeta en Claude Code y escribir "hola".
